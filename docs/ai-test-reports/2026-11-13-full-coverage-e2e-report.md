# Reven 全功能端到端浏览器测试与功能验收报告（2026-11-13）

> **测试目标**：对当前部署在自有服务器生产环境（`https://reven.wangyiyang.cc`，版本 `v0.9.0`）的 Reven 个人经营工作台进行 100% 全功能链路浏览器自动化探测与验收。  
> **执行工具**：`agent-browser`（Chromium 自动化会话 `reven-qa`）。  
> **数据卫生与红线**：所有测试数据均带 `AITEST-` 前缀，覆盖新增、详情查看、状态变更、关联子表和二次确认删除全生命周期。测试结束后查验数据库，确保相关业务表均为 0 条残留，保证零数据污染。

## 二、逐模块详细测试过程与证据

### 1. 认证与全局壳层 (Auth & AppShell)
- **密码登录**：打开 `https://reven.wangyiyang.cc/` 自动重定向至 `/login`。输入管理员密码提交后，成功置换 `reven_session` HttpOnly Cookie 并跳转至 `/` 工作台。
- **深色模式**：点击侧边栏「深色」按钮，页面 `html` 元素即刻切换为 `dark` 主题样式；再次点击无缝切回浅色模式。
- **主导航结构**：验证主导航包含完整的 10 个顶层入口（工作台、CRM、人才库、财务、项目、SOP、RSS 展开菜单、品牌管理、集成设置、系统状态）。
- **登出保护**：点击「退出」按钮，会话 Cookie 立即注销，页面重定向至 `/login`，直接访问受保护业务路径均被 401 拦截并跳转。

### 2. 工作台 (Dashboard `/`)
- **集成缺失提醒**：页面顶部展示「6 项集成未配置，相关能力不可用」黄色 Banner（飞书、百度翻译、阿里翻译、Embedding、Agent LLM、腾讯云 COS），附带「前往集成设置」直达链接。
- **财务待收款卡片**：聚合显示待收款项笔数、金额与逾期金额，支持一键前往财务待收款页面。
- **RSS 待审核卡片**：展示待审核条目数、已保存素材数，并显示「最近抓取：成功 · 11/13 06:00」调度信息。
- **CRM 待跟进卡片**：实时展示今日到期与逾期跟进客户数。
- **进行中项目卡片**：统计进行中项目数量，支持一键直达项目台账。

### 3. CRM 客户管理 (`/crm` & `/crm/customers/:id`)
- **空态与检索**：无数据时列表展示「暂无匹配客户。」；支持按「客户名称搜索」、「关系状态」（潜在客户/跟进中/合作客户/暂停跟进/已流失）和「跟进计划」（已逾期/今天/未来/无计划）联动筛选。
- **抽屉创建**：点击「新建客户」，右侧滑出抽屉表单。填写 `AITEST-测试客户-01`、状态「跟进中」、来源「线上推荐」、备注「自动化浏览器测试创建」，点击添加，Toast 提示「客户已添加」，列表即时渲染新数据。
- **客户详情页**：点击客户名称跳转至 `/crm/customers/:customerId`：
  - **客户档案**：展示状态 Badge、来源、备注以及派生的当前行动与计划。
  - **联系人管理**：在联系人表单录入姓名「张三」、职位「采购总监」、手机「13800000000」、邮箱，勾选「设为主要联系人」，提交后成功在联系人卡片展示「主要联系人」标签。
  - **跟进记录与计划派生**：在跟进表单中选择方式「微信」、关联联系人「张三」、内容「沟通 Q4 采购意向，客户反馈预算已批复。」、下一步行动「发送正式报价单」、下次跟进日期「2026-11-20」。保存后，跟进记录上屏，客户主档案的「下一步行动」自动联动更新为「发送正式报价单」。
- **安全删除**：返回客户列表，点击行内「删除」，弹出 Dialog 二次确认「该客户的联系人和跟进记录也会被删除，且无法恢复。」；点击确认删除，Toast 提示「客户已删除」，级联数据一并清除。

### 4. 人才库 (`/talents` & `/talents/:id`)
- **列表与多维筛选**：人才列表支持搜索、状态筛选（候选/接洽中/已合作/搁置）、跟进到期筛选以及技能标签筛选。
- **人才档案录入**：点击「新建人才」，抽屉表单支持录入姓名、状态、机构、联系方式、标签、喜好、能力、合作条件、费率（金额 + 单位：按小时/天/项目）和评分（1-5 星）。录入 `AITEST-李四`（接洽中、¥1500.00 按天、★ 5/5），提交后列表格式化展示。
- **人才详情页**：点击进入详情：
  - 档案区展示评分、费率及偏好；
  - 提供工作履历表单（公司、职务、起止月份、经历描述）；
  - 提供毕业院校表单（学校、学位、专业、起止月份）；
  - 提供跟进记录表单（沟通方式、发生日期、沟通内容、下次跟进）。
- **安全删除**：在列表点击删除，弹出「该人才的跟进记录也会被删除，且无法恢复。」确认框，确认后清理完毕。

### 5. 财务管理 (`/finance/*`)
- **三层子路由布局**：
  - **概览 (`/finance/overview`)**：动态统计「本月实收」、「本月实付」、「收支净额」五张核心经营卡片，展示待处理款项列表。
  - **收支流水 (`/finance/ledger`)**：提供年月月份选择器、收支类型下拉过滤、分类检索与搜索框；
  - **待收待付 (`/finance/pending`)**：按「待收」与「待付」Tab 分页展示未结清款项。
- **4 种快捷录入**：页面提供「记收入」、「记支出」、「新增待收」、「新增待付」快捷按钮。
- **校验与闭环测试**：
  - 空名称提交测试：Toast 精准报错「请填写名称」，拦截空提交；
  - 录入真实流水 `AITEST-咨询服务费`（金额 ¥5,000.00，分类「咨询」），提交后概览实收即时跳变至 `¥5,000.00`，净额同步计算；
  - 进入收支流水列表，点击删除按钮，确认对话框提示「删除后无法恢复，请确认这条财务记录已不再需要。」；确认删除后金额自动归零，恢复基线。

### 6. 项目库 (`/projects`)
- **项目台账维护**：支持名称、目标、部门、截止日以及 GitHub 仓库 URL。
- **外部链接渲染**：新建项目 `AITEST-项目-全功能验收`，填入 `https://github.com/wangyiyang/Reven`，保存后在表格内以超链接形式渲染，可新开标签页跳转。
- **安全删除**：具备二次删除确认机制，删除后列表恢复空态。

### 7. SOP 标准作业流程 (`/sops`)
- **流程规范沉淀**：支持四大流程类型（程序 / Checklist / 话术 / 方法论）与三态生命周期（草稿 → 试行 → 正式）。
- **内容查看与复制**：新建 `AITEST-版本发布验收规范` 后，点击行内「查看」滑出只读详情抽屉，展示完整 Markdown 内容并支持一键「复制内容」。
- **安全删除**：确认对话框拦截误删，测试后干净移除。

### 8. RSS 内容发现与源/词配置 (`/rss/*`)
- **内容发现 (`/rss/candidates`)**：
  - 待审核 Tab 与已保存素材 Tab 切换平滑；
  - 无新内容时显示明确空态文案与调度等待提示。
- **源管理 (`/rss/sources`)**：
  - 提示每日 06:00 自动抓取规则；
  - 提供新建源抽屉（支持 URL、名称、抓取周期配置）。
- **关键词维护 (`/rss/keywords`)**：
  - 正向关键词与反向关键词分区独立管理；
  - 各区配备独立搜索框与新增入口。

### 9. 品牌管理 (`/brand`)
- **品牌档案**：支持品牌名称、默认署名、一句话介绍、主色（带调色板取色器与 Hex 文本联动）、正文字体、品牌主页与简介。支持「保存草稿」和版本发布控制。
- **品牌素材库**：图片素材上传区（支持 PNG/JPEG/GIF/WebP ≤10MB），可归档为标志、二维码、封面或其它用途。
- **渠道模板**：
  - 支持「微信公众号」与「个人博客」双渠道模板配置；
  - 微信模板支持排版主色、字号（12-24px）与文末图文模块顺序编排。

### 10. 集成设置 (`/integrations`)
- **多提供商覆盖**：提供飞书应用、百度翻译、阿里翻译、Embedding、Agent LLM 完整卡片。
- **安全脱敏保证**：已保存或未保存的 API Key / App Secret 均只提供输入与替换通道，界面与 API 绝不回显任何明文密钥。
- **Agent LLM 扩展**：支持设置默认模型（如 `deepseek-official/deepseek-v4-flash`）以及附加模型列表，直接打通飞书 `/model` 动态切换。

### 11. 系统状态 (`/system`)
- **全链路健康巡检**：
  - 后端服务：正常（服务标识 `reven`）；
  - 数据库：正常（实时执行 `SELECT 1` 探活）；
  - RSS 调度：正常（显示最近心跳时间戳，如 `2026年11月13日 19:41`）；
  - 提供手动「刷新」按钮，可实时拉取最新运行状态。
