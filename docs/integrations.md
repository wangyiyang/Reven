# 可选集成

先完成 [RSS → Reven 本地素材库首次验收](self-hosting.md)。以下集成由使用者自行申请账号、开通接口并承担费用；基础启动和素材采纳不需要共享凭据或维护者账号。

## 按能力选择

| 能力 | 配置位置 | 用途 | 未配置时 |
| --- | --- | --- | --- |
| 百度 / 阿里翻译 | 集成设置 → 对应翻译服务 | RSS 翻译，按优先级故障切换 | 尝试 Qwen 回退，仍不可用则保留原文 |
| Embedding | 集成设置 → Embedding | RSS 语义筛选 | 使用字面与 BM25 筛选，显示语义降级 |
| Qwen 复核与翻译回退 | 自托管 `.env` 中 `SILICONFLOW_API_KEY` 等 | RSS 模型服务 | 模型复核跳过或降级，不影响人工采纳 |
| Agent LLM | 集成设置 → Agent LLM | Agent 对话与工具调用 | Agent 不可用；配置后需重启 Reven |
| 飞书通知 | 集成设置 → 飞书 | RSS 每日汇总 | 不发送群机器人通知 |
| 飞书交互机器人 | 集成设置 → 飞书应用 | 在飞书审核、采纳或忽略候选 | 继续在网页完成人工审核 |
| 腾讯云 COS | 自托管 `.env` | 品牌图片上传与公开访问 | 图片上传返回 `cos_not_configured`，RSS 素材仍可保存 |

环境变量可选项在 [示例文件](../infra/self-host/.env.example) 中保持注释。填写自己的值后，执行 `dc up -d --force-recreate --wait reven`；`dc` 沿用自托管指南定义。UI 中的集成 Secret 加密保存在数据库中，升级和恢复必须保留原主密钥。

翻译、Embedding、Qwen 和 Agent LLM 是不同的配置与计费入口。只填写 Agent Key 不会同时启用 RSS 模型服务。启用外部 AI 后，相应条目内容、关键词或对话会发送给所选服务商，按自己的数据要求决定是否启用。

## 品牌图片与 COS

RSS 采纳只保存在 Reven 数据库中，不依赖 COS。品牌图片上传需要自己的 COS Bucket 与写入凭据：

1. 准备专用 Bucket 和最小权限凭据；启用品牌图片的公开访问地址，不在该 Bucket 存放私密资料。
2. 填写 `COS_BUCKET`、`COS_REGION`、`COS_SECRET_ID`、`COS_SECRET_KEY`、`COS_PUBLIC_BASE_URL`，可保留 `COS_ASSET_PREFIX=assets/sha256`。公开地址使用 HTTPS。
3. 重建 Reven 容器后，在品牌页面上传专用测试图片，核对图片可见及素材记录。对象使用内容寻址，数据库回滚不会自动删除已经上传的对象。

品牌模板目前只保存配置。Notion 同步、博客自动发布和微信公众号草稿流程已移除，不需要为当前版本配置这些账号。

## 飞书与费用

“飞书”卡片配置群机器人的 Webhook，用于通知；连接测试会发送真实测试消息，应使用自己的测试群。“飞书应用”需要自建应用凭据、事件长连接和允许操作的成员 Open ID 白名单；未验证权限前保持停用。

网页与飞书共用素材采纳服务；重复采纳不会重复保存。首次验收可只使用网页，不需要发送飞书消息。

域名、服务器、存储与流量，以及翻译、模型和飞书服务可能产生费用或额度限制。自行在服务商控制台核对并设置预算与告警；Reven 不管理这些账单。
