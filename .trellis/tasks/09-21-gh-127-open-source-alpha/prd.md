# 完成开源 Alpha 发布准备（#127）

> 合并范围更新：`main` 的 `7edafd7`（#128）已移除 Notion、稿件发布、renderer、Doocs 与 Ruby/bubblewrap 运行依赖。用户要求本分支解决与 main 的冲突，因此当前实施保留该产品决策，首次流程改为 RSS → 人工审核 → Reven 本地素材库；以下早期设计与验收记录中涉及退役能力的内容仅保留为历史依据。当前合并验证见 `research/merge-main-validation.md`。

## 目标与用户价值

交付可以对外发布的单用户、自托管内容运营工作台 Alpha：外部开发者无需维护者的账号、凭据或私有基础设施，即可按文档安装并跑通 RSS → 人工筛选 → Reven 本地素材保存的首次使用流程。

来源：https://github.com/wangyiyang/Reven/issues/127

## 已确认决策

2026-09-21，用户分别以“听你的建议”和“同意你的建议”确认两轮 Q1–Q6：

- D1：接受商业使用和闭源衍生，优先扩大使用与贡献；原创部分采用 Apache-2.0。
- D2（已由 #128 主分支决策取代）：原计划 RSS → Notion；当前版本首次验收采用 RSS → 人工筛选 → Reven 本地素材保存。Notion、博客及微信发布已退役。
- D3：本次保留现有生产部署兼容性，提供通用自托管路径；现有生产环境迁移另行安排。
- D4：按用户确认，将个人原创部分版权持有人登记为 Wang Yiyang；第三方代码保留原有版权与许可，不被根许可证覆盖。
- D5：Alpha 正式支持 Linux AMD64；ARM64 和 Docker Desktop 暂不承诺支持，后续经验证再增加。

## 背景与证据

检查基线为主分支 `776167540c5d6935d7462b0ad9d3f9c1bf2923b2`。

- 当前缺少项目级许可证；vendored Doocs 已保留 WTFPL v2 及固定提交信息。
- `.trellis/.version:1` 为 0.6.15，该固定版本上游为 AGPL；已确认 `.trellis/scripts/task.py` 等存在实际模板复制，未发现模板授权例外。当前应用运行镜像不包含这些工具，须单独保留其许可，不能宣称全仓 Apache-2.0。
- `vendor/doocs-md/shared/src/configs/api.ts:5` 包含第三方 Token 列表，有效性未验证；禁止在规划、Issue 或报告中复制凭据值。
- 先前模式扫描中历史 DeepSeek Key 命中已确认为占位值，尚未完成专用工具的完整历史扫描。
- `server/src/reven/config.py:44` 仅允许 HTTP origin；入口与镜像脚本存在维护者环境绑定。
- `.github/workflows/ci.yml:67` 已使用标准 PostgreSQL 17 验证后端及迁移，未发现 Supabase 专有服务依赖。
- `infra/docker/entrypoint.sh:15` 已提供自动数据库迁移，迁移失败会停止启动。
- 无外部 API 凭据可以启动基础服务；Notion 流程需使用者自己的 Notion 集成。完整稿件同步另有 COS 依赖，不能宣称全部功能均无需云账号。
- 当前没有完整的多架构构建与沙箱验证矩阵；博客和渲染器需要宿主支持 Linux bubblewrap 沙箱。
- `server/src/reven/rss/scheduler.py:24` 每天上海时间 06:00 后调度，`server/src/reven/rss/discovery.py:101` 复用已结束的当日运行；当前无手动抓取 API，因此当天已执行后新增源可能需要等待次日。

部署细节见 `research/deployment-design.md`；许可与扫描边界见 `research/disclosure-design.md`；启动和首次流程依据见 `research/bootstrap-facts.md`、`research/first-run-validation.md`。

## 需求

- R1 授权：确认原创代码授权归属和许可证；核对 vendored 代码、锁定依赖、字体与镜像分发组件，保留必要声明。
- R2 公开内容：扫描并复核拟公开的分支、标签、历史和附属资料；清理不需要的凭据配置，避免上游同步重新引入；仅保存脱敏结果。
- R3 安全部署：支持 HTTPS、正确的 Origin/CSRF 和安全 Cookie；说明 HTTP 的本地开发及可信网络边界。
- R4 独立运行：提供通用参数及无需维护者私有镜像权限的构建或获取路径，并维持镜像校验约束。
- R5 兼容性：现有部署路径继续可用；本次不将开源准备与现有生产环境迁移绑定。
- R6 使用文档：说明安装、首次登录、必需与可选集成、第三方费用、升级、备份恢复及回滚，并覆盖 D2 的核心流程；明确正式支持平台和首次 RSS 抓取的调度等待。
- R7 协作与发布：补齐贡献指南、安全反馈方式、Alpha 已知限制和干净环境验收记录。

## 验收标准

- [ ] AC1（R1）：原创代码许可明确，授权归属无待解决项，必要第三方声明随分发物保留。
- [ ] AC2（R2）：拟公开内容与历史完成专用扫描及人工复核，无未处理的真实凭据或不应公开的信息。
- [x] AC3（R3）：HTTPS 下认证、CSRF、会话 Cookie 均通过有意义的行为验证。
- [ ] AC4（R4、R6）：陌生用户不使用维护者账号或私有仓库权限，按文档完成安装和首次登录。
- [ ] AC5（R6）：完成 RSS → 人工筛选 → Reven 本地素材保存的验收，验证重复采纳幂等与重建后持久化；不依赖退役的 Notion 集成。真实 Feed 的发现与确定性候选验收分别记录。
- [x] AC6（R5）：现有生产配置的兼容性与回滚路径有验证证据。
- [ ] AC7（R7）：质量检查通过，贡献、安全反馈、安装与运维文档齐备，支持平台及已知限制清楚可见。

## 范围之外

- 多租户 SaaS、完整 ERP、新增 Agent 能力。
- 为消除全部云依赖而新增本地对象存储或其他存储适配。
- 本次直接迁移现有生产入口或修改其部署凭据。
- 未经扫描结果和具体方案确认而重写 Git 历史。
- 规划及代码准备阶段直接切换仓库可见性或对外发布镜像。
- 新增 RSS 手动重跑入口或改变按自然日执行一次的业务语义。
