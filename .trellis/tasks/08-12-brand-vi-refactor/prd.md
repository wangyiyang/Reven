# PRD · 应用界面品牌 VI 重构

## 目的 / 结论

将 Reven 全部前端界面从当前「古典纸墨风」（米色纸底 + 宋体/楷体 + 朱红/蓝）整体重构为「翊行代码」VI v2.1 工业极简风（碳黑 + 冷白 + 终端绿 + 无衬线字体栈），使应用与个人品牌视觉体系统一。

## 背景

- 品牌规范来源：Notion「YY · Personal Brand Prompt Kit」Hub + VI 核心规范 + Logo 文档（v2.1 几何字标 `{翊}` 已交付全套 SVG/PNG 资产）。
- 当前 `web/src/index.css` 使用 `--paper: #f3efe5` / `--ink: #171714` / `--red: #b62a1d` / `--blue: #155cad`，宋体正文 + 楷体标题 + 纸纹网格背景——与 VI v2.1「去古典化」方向完全相反。
- VI 铁律：三色系统（碳黑 `#0A0A0A` / 冷白 `#FAFAFA` / 终端绿 `#00E676`），不引入第 4 色（含灰色，中间色用碳黑透明度）；终端绿是「信号」，单页面仅作点睛；禁用宋体/楷体/书法元素。

## 需求范围

### 包含

1. **设计令牌层**（`web/src/index.css`）：重写 CSS 变量为三色系统；接入字体栈（思源黑体 / Inter / JetBrains Mono）；删除纸纹背景；按 VI 字号阶梯与行高定义排版基准。
2. **Logo 与品牌出场**：Logo 资产（master.svg / mono-white.svg / favicon-16/32.png）落入 `web/public`；app-shell 侧栏展示 `{翊}` + 「Reven」产品字标（用户批准：VI 管视觉不改产品名，不替换为「翊行代码」）；替换 favicon。
3. **组件与页面层**（`web/src` 全部）：按钮、卡片、导航、徽章、表格等组件及 articles / rss / integrations 各页面去朱红/蓝色，套用三色规则（细灰 `#E5E5E5` 1px 边框、hover 终端绿、链接绿 + hover 下划线、引用块绿竖线）。
4. **渲染器主题**（`renderer/src/render.ts`）：微信预览主题主色 `#0F4C81` 改为终端绿体系；代码块深色底 `#0A0A0A` + 终端绿关键字；引用块左侧绿竖线。
5. **深色模式**：碳黑底 + 冷白字 + 终端绿点睛（反白版 Logo），跟随系统或手动切换。

### 不包含

- 公众号封面 / OG 图生成功能的品牌化（属内容资产，不在应用界面范围）。
- vendor/doocs-md 内部包的改造（仅通过 renderer 主题变量覆盖输出样式）。
- 文案、信息架构、交互流程的改动。

## 约束

- 终端绿 `#00E676` 不做大面积填充（按钮主 CTA 除外时以碳黑为主、绿点睛）；禁霓虹/发光/渐变。
- 字体全部开源免费（思源黑体 / Inter / JetBrains Mono），交付方式需离线可用（本地打包，不依赖 CDN）。
- 不改动业务逻辑与 API 契约；纯样式层重构。
- 遵循现有 Tailwind v4 + CSS 变量技术路线。

## 验收标准

1. `pnpm -C web build` / `lint` / `test` 全绿；`renderer` 构建测试通过。
2. 全应用无 `#f3efe5` / `#171714` / `#b62a1d` / `#155cad` / 宋体 / 楷体残留（除历史注释）。
3. 浅色模式：冷白底、碳黑字、终端绿仅出现于链接 / hover / CTA 点睛 / 状态指示。装饰性绿元素单屏 ≤ 3 处；链接、粗体、状态徽标属 VI 批准的功能性绿色，不计入该配额。
4. 深色模式：碳黑底、反白 Logo、绿色不变；两模式切换无样式破损。
5. 微信预览渲染输出：主色终端绿、引用块绿竖线、代码块深色底 + 绿关键字。
6. 顶栏与 favicon 使用 v2.1 Logo 资产，无拉伸/改色/违规变体。
