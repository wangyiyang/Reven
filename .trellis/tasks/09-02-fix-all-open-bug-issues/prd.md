# PRD · 处理全部开放 Bug Issues

## Goal

处理 `wangyiyang/Reven` 在 2026-09-02 盘点到的全部 7 个开放 `bug` Issue（#83、#100–#105），使每个 Issue 都有可验证的修复或“已修复/不可复现”的证据，并在 GitHub 上关闭。

## Background

- #83 的目标代码已经由 PR #86 / commit `672a408` 合入 `main`：发布镜像包含 `infra/`，部署脚本会导出、校验、同步、健康检查、按需 reload Caddy，并在失败时恢复。该 Issue 当前主要缺少回归验证与关闭。
- #100–#105 均由 2026-09-02 的 QA 审计创建，覆盖分页、CRM/人才库布局和状态、财务一致性与口径、WCAG AA 对比度。
- 当前主干是 `75a0181`，与 `origin/main` 一致；用户已有的 `dogfood-output/` 未跟踪目录不属于本任务，必须保留。
- `.trellis/spec/web/frontend/brand-vi.md` 仍描述旧的碳黑/冷白/终端绿方案，但应用已由 2026-08-19 合并的 PR #40（`9c9b0f8`）明确切换为当前 Notion 风格蓝灰主题；用户已确认 #105 保留当前 Notion 风格并修复对比度。

## Requirements

1. **#83 部署 infra 漂移**：验证现有镜像导出、精确同步、Caddy 变更 reload、失败回滚测试；若验证通过，不重复改代码，使用证据关闭 Issue。
2. **#100 稿件分页越界**：非法页码归一到第 1 页；大于最后一页的页码自动归一到最后一页；URL 与实际展示页一致，分页入口不因越界永久消失。
3. **#101 CRM 详情排版**：1280px 桌面视口下完整显示日期；邮箱可在合理边界换行而不强制逐字符断词；主要联系人表单标签和徽标不拆词。
4. **#102 人才库状态**：桌面空态位于表格 `tbody` 内并跨越全部列；跨字段验证失败后姓名、费率、已确认标签等全部表单状态保持不变。若标签问题在当前主干不可复现，增加回归测试并以证据关闭该子问题。
5. **#103 财务删除一致性**：UI 只有在 DELETE 成功后才移除记录；失败时保留原数据并显示错误；快速连续操作不得出现“UI 已删、服务端未删”的假成功状态。
6. **#104 财务口径**：页面不再承诺尚未实现的“跑道”；核心卡改为“已收收入 / 已付花销 / 现金净额”，仅统计 `已收`/`已付`，`已记录` 不计入现金汇总，应收、应付保持独立展示。
7. **#105 WCAG AA**：当前主题下所有普通文本及文字按钮达到至少 4.5:1；非文字 UI/大字按 WCAG AA 对应阈值；浅色与深色模式均通过 axe-core color-contrast 审计。
8. 每个子任务必须有针对性回归测试；父任务最终运行 web lint/test/build、server 相关测试、部署脚本测试和浏览器可访问性回归。
9. 在 `codex/` 前缀功能分支上实施，禁止直接提交到 `main`；提交采用 Conventional Commits。
