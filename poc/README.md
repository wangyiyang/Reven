# 飞书 Bot POC — 文字+附件闭环

为 Reven（AI 原生家电零售经营平台）验证飞书 Bot 通道能力。

## 目录结构

```
poc/
├── main.py               # 长连接入口 + 事件注册 + 消息派发
├── aggregator.py          # SessionAggregator 消息配对聚合器
├── handlers/
│   ├── __init__.py
│   ├── downloader.py      # 附件下行：收文件/图片落盘
│   └── uploader.py        # 附件上行：上传文件/图片并发送
├── tests/
│   ├── __init__.py
│   └── test_aggregator.py # 聚合器纯逻辑单元测试（10 项）
├── downloads/             # 收到的文件临时存储（已 gitignore）
├── .env                   # 凭据（已 gitignore）
├── .env.example           # 凭据模板
└── README.md              # 本文件
```

## 运行方式

### 前置条件

- Python ≥ 3.8
- 已安装依赖：`pip install lark-oapi python-dotenv openpyxl`
- 飞书企业自建应用已创建，已开通权限：
  - `im:message`
  - `im:resource`
  - 事件订阅方式：**长连接**
  - 订阅事件：`im.message.receive_v1`

### 启动

```bash
cd poc
cp .env.example .env
# 编辑 .env 填入 FEISHU_APP_ID 和 FEISHU_APP_SECRET
python main.py
```

控制台看到 `connected to wss://...` 即表示连接成功。

### 运行单元测试

```bash
cd poc
python tests/test_aggregator.py
```

## 实现覆盖

| 阶段 | 功能 | 状态 |
|------|------|------|
| M1 | Echo 基线：长连接收消息 → 原文 reply | ✅ |
| M2 | 附件下行：`message_resource.get` 下载文件/图片 | ✅ |
| M3 | 附件上行：`file.create` 上传并发送 | ✅ |
| M4 | SessionAggregator 聚合器 + 单元测试 10 项 | ✅ |
| M5 | 幂等去重 (message_id) + 3 秒时限 (线程池) + 聚合器定时器 | ✅ |

### SessionAggregator 覆盖路径

- ✅ 先文字后文件 → 窗口到期后聚合
- ✅ 先文件后文字 → 窗口到期后聚合
- ✅ 只有文字 → 窗口到期后成一次请求
- ✅ 只有文件 → 窗口到期后按"无指令附件"处理
- ✅ 窗口内多文件 → 聚合为同一请求的多附件
- ✅ 不同发送者不聚合
- ✅ 去重检测
- ✅ 线程安全

## 已知约束

- **3 秒处理时限**：事件 handler 必须在 3 秒内返回，否则飞书超时重推。本 POC 通过 `message_id` 幂等去重 + `ThreadPoolExecutor` 将重活异步化解决。
- **断线重连**：`lark.ws.Client` 的自动重连行为因版本而异。如果发现断线后不自动重连，建议用 systemd/supervisor 做进程级守护。
- **文件大小上限**：以飞书官方文档为准（一般文件 ≤ 20MB，图片 ≤ 10MB），超大文件会触发接口报错，Bot 应回复友好提示而非崩溃。
